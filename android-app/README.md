# 工时日记 Android 版

原生 Android 个人考勤应用（0.0.10）。每日记录写入手机本地 SQLite 数据库，不使用浏览器存储，也不需要联网。底部有月度、每日、工具三个页面；月度页显示日历和月度工时，每日页顶部按已过工作日 × 8 小时计算欠工时或超出工时。工时数字可点击切换分钟或小时（小时显示三位小数）；打卡时间使用滑动条选择。支持工作日/休息日调整、计薪时段自动计算，以及 CSV 导出和恢复。应用会把数据库纳入 Android 系统备份；系统备份是否运行取决于设备的备份设置，建议定期另存 CSV。

## 规则

- 按实际时间记录上下班打卡；上班可早于 08:00，提前时间也会计入工时。
- 上班时间至 12:00、13:30–17:30、18:00–24:00 为计薪时段。
- 12:00–13:30 和 17:30–18:00 不计工时。
- 每日卡片直接显示工作日或休息日；点击状态标签可快速切换，点击卡片可编辑上下班时间；只录入一侧打卡时会提示待补录。
- 启动时默认打开每日页，并将独立滚动的每日记录区定位到今天；底部标签或左右滑动可切换月度、每日和工具页面。
- 周一至周五默认工作日，周末默认休息；日期可单独切换。
- 工时差额按“已过工作日 × 8 小时 − 已记录计薪工时”计算；正数显示欠工时，负数显示超出工时。未录入的工作日也计入目标工时。

## 本机构建

使用 Android Studio 打开此目录，等待 Gradle 同步后运行 app 配置，或在已安装 JDK 17、Android SDK Platform 34 与 Build Tools 的环境中执行：

    gradle assembleDebug

构建产物为 `app/build/outputs/apk/debug/app-debug.apk`。项目附有 GitHub Actions 构建流程；普通主分支推送会生成保留 30 天的构建附件。带有 `[release]` 标记的主分支提交成功构建后，会发布带版本号的 Release，并提供直接下载的 `.apk` 文件。

## 数据备份与恢复

在“工具”页点击“导出备份”，选择手机上的文件位置保存 CSV。恢复时点击“恢复备份”并选择 CSV；相同日期的内容会被导入记录覆盖。CSV 列格式与网页版本兼容，可从网页版本导出后导入 Android 版。

此版本使用 Android 原生 API，不依赖第三方库。
