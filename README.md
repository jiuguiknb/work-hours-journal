# 工时日记

一款离线可用的个人考勤网页应用。填写每天的上班、下班打卡时间，自动按公司的计薪时段计算工时，并汇总月度目标、工作日均工时和当前欠工时。

除网页版本外，android-app/ 目录还提供了将记录保存在手机本地数据库的原生 Android 版本。Android 0.0.10 包含月度日历和月度/每日/工具三栏导航；每日页会显示已过工作日目标、实际工时，以及欠工时或超出工时。点击首页工时数字可在分钟和小时之间切换（小时保留三位小数），打卡时间使用滑动条选择。
安卓版本号显示在应用名称中，包含月度日历、每日工时结算和月度/每日/工具三栏导航。每日结算会比较已过工作日目标与实际计薪工时，因此既能显示欠工时，也能显示超出工时。

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖、启动服务器或联网。数据保存在当前浏览器的本地存储中；点击“导出本月”可下载 CSV 备份。

## 计算方式

- 按实际时间记录上下班打卡；上班时间不限制在 08:00–09:00，08:00 前的打卡时间也会计入工时。
- 计薪时段为上班时间至 12:00、13:30–17:30、18:00–24:00；下班时间可以填写为 `24:00`。
- 12:00–13:30 和 17:30–18:00 不计工时，其余时段按打卡区间计算。
- 每日卡片清楚显示工作日或休息日；点状态标签可直接切换，点卡片或“编辑”可设置上下班时间。只录入一侧打卡时会提示待补录，不会误报时间顺序错误。
- 周一至周五默认是工作日，每个工作日目标为 8 小时；周末默认休息。可将特定日期切换为工作日或休息日，以记录公司假期和调休。
- 欠工时按“已过工作日 × 8 小时 − 已记录计薪工时”计算，低于零时显示为 0；均值按已过工作日计算，未打卡的工作日也计入分母。
- 休息日录入的实际工时仍会计入已记工时。

## 构建

应用是一个自包含的静态网页，`index.html` 即为可运行的构建产物。

安卓 APK 由 GitHub Actions 构建。标记为 `[release]` 的主分支提交会在构建成功后创建版本 Release，Release 页面提供可直接下载的 `.apk` 文件；Actions 的普通构建附件仍由 GitHub 打包成 ZIP。
